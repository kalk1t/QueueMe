# Security

## Reporting security issues

- Do not report security issues in public issue trackers.
- Use GitHub private vulnerability reporting or contact the repository owner privately.

## Prohibited secret material

Never commit:

- API keys
- Access tokens
- Payment credentials
- Twilio credentials
- Stripe secrets
- AWS credentials
- Firebase service-account credentials
- Signing keys
- Customer phone numbers
- Production database exports

Security controls and reporting details will be expanded in later milestones.
